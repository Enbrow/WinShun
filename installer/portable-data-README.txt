有这个 data 文件夹，Win顺 就是便携版：设置、搜索记录、剪贴板历史、收藏夹、插件和索引都存在这里，
不放在 %APPDATA%\WinShun 和 %LOCALAPPDATA%\WinShun。

第一次启动时，这台电脑上原来的设置和数据会复制过来（原来的不动，不想要可以自己删）。
整个文件夹可以拷到 U 盘或别的电脑。
不想用便携方式：先退出 Win顺，再删掉这个 data 文件夹。

With this "data" folder WinShun is portable: its settings, history, clipboard, favorites,
plugins and index are kept here, not in %APPDATA%\WinShun and %LOCALAPPDATA%\WinShun.
On the first start, what this PC already has there is copied in (the originals stay).
To stop: quit WinShun, then delete this folder.
