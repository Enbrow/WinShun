# Win顺自带的应用别名：应用除了开始菜单里显示的名字，还能按这里写的名字和简写找到（AppCatalog）。
#
# 每段一个应用，方括号里是给人看的名字（wsbench --apps 用它报告这台电脑上哪些段对上了应用）。
# 先写怎么认出这个应用，满足一条就算，依次是：
#
#   id      = Microsoft.WindowsCalculator_8wekyb3d8bbwe!App    AppUserModelID（商店和 Windows 自带的应用）
#   package = TelegramMessengerLLP.TelegramDesktop_t4vj0pshhgkwm  应用包的系列名（AppUserModelID 里 ! 前面那段）：
#                                                              包里的每个应用都算
#   program = WeChat; Weixin    快捷方式指向的程序的文件名，不带 .exe，不分大小写，整个相同才算
#                               （“WXWork”里有“wx”不算）。几个程序共用一个文件名的（Chromium 系的浏览器
#                               大多叫 chrome.exe）写上它所在的文件夹：Google\Chrome\Application\chrome，
#                               路径以此结尾才算。不要写 Update、launcher 这类许多程序共用的名字。
#                               经 cmd、powershell、mmc、rundll32 等运行别的东西的快捷方式（VS 的开发者
#                               命令提示符是 cmd.exe /k vcvars64.bat）不算这个程序，也就对不上这里。
#   title   = WPS Office        开始菜单里显示的名字，整个相同，不分大小写。上面几种都用不了时才写，
#                               而且不能是“Settings”“帮助”“卸载”这种别的程序也会用的名字。
#
# 再写它还叫什么，用分号或 | 隔开：
#
#   names   = Calculator | 计算器   它自己在各语言里的名字（含开始菜单显示的那个）。商店应用的名字按
#                                 “设置 → 时间和语言 → 语言和区域”里首选语言列表的第一个取，和 Windows
#                                 的显示语言无关：列表里英语在前，中文 Windows 上计算器也叫“Calculator”，
#                                 搜“计算器”就找不到。几个名字都能搜，用哪个找到的就显示哪个。
#   aliases = 微信; WeChat          别的叫法，和名字一样匹配（拼音自动可用：“wx”“weixin”能找到“微信”），
#                                 完整输入时排得和名字完全相同一样高；显示的仍是开始菜单里的名字
#                                 （便携版微信的快捷方式叫“启动微信”）。
#   short   = ps                    简写，只有完整输入（不分大小写）时才算，排在名字完全相同之后、程序
#                                 文件名之前；只输一部分（“p”“s”“pss”）不算，Photoshop 不会因为简写
#                                 被带出来。只能是字母和数字，至少两个。别和常用的拼音撞上：输“an”的
#                                 多半要“安”“按”（2026-10-19 本机对上 76 个设置），所以 Animate 不写；
#                                 “ai”只对上 7 个，多是“AI 组件”这类，Illustrator 照写。
#
# 只写本来搜不到的：开始菜单里的名字、程序文件名，以及它们的拼音、首字母都已经能搜
# （PyCharm、Steam、迅雷不用写）。
