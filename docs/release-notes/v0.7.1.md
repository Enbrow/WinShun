## 下载 · Download

Download **WinShun-0.7.1-x64-setup.exe** below and run it. If an older version is installed, running it upgrades in place and keeps your settings and index. Requires Windows 10 or 11, 64-bit.

## 新功能 · What's new

- 🗂️ **按类型找**：选中“文件”后，搜索框下面一排类型：文件夹、文档、图片、视频、音频、压缩包、程序、电子书、代码，`Tab` 依次切换，`Shift+Tab` 换范围。点 `+` 或在设置的“文件类型”里自己加、改名、排顺序；选的类型下次打开还在。
  **Find by kind**: under Files, a row of kinds below the search box: folders, documents, pictures, videos, audio, archives, programs, e-books, code. `Tab` steps through them, `Shift+Tab` changes the scope. Add your own, rename and reorder them with `+` or in Settings → File types; the kind you picked is still there next time.
- 🔢 **序号标在图标上**：每行的序号一直标在图标角上，`Ctrl+1`～`Ctrl+9` 直接打开，不用先按住 `Ctrl` 等它出来。
  **Numbers on the icons**: each row's number is always on its icon; `Ctrl+1`…`Ctrl+9` opens it without holding `Ctrl` first.
- 🔎 **任务栏搜索框放在开始按钮右边**（Windows 11，设置里打开，默认关）：像 Windows 自带的搜索框一样，任务栏图标往右让出位置。打开时 Win顺 会让资源管理器加载一个小组件来留出这段位置，Win顺 退出时自动还原。和 TranslucentTB、Windhawk 这类改任务栏的工具不能同时用，设置里会说明。
  **Taskbar search box right of Start** (Windows 11, off by default, in Settings): like Windows' own search box, the taskbar icons move over for it. WinShun has File Explorer load a small component to make the room, and it is given back when WinShun quits. It can't work alongside taskbar tools such as TranslucentTB or Windhawk; Settings says when one is in the way.
- 💡 **没搜到的地方会提示**：内容搜索默认跳过太大的文件、系统和程序文件夹、没列出的文本类型，搜完在列表末尾告诉你各有几个，点一下就把它们也搜一遍；插着没收录的 U 盘时，也会提示顺手搜一下它。
  **Hints for what was left out**: content search skips files over the size limit, system and program folders and unlisted text types by default; the end of the list says how many of each, and one click searches them too. An unindexed USB drive that is plugged in is offered the same way.
- 🈶 **打错同音字也能找到**：输入里有汉字、一个结果都没有时，自动按读音再找一遍（年度报高 → 年度报告），结果上标明是按读音找到的。
  **Homophones**: when a Chinese query finds nothing at all, it is tried again by sound (年度报高 finds 年度报告), and the results say so.
- 🛠️ **修复**：开着透明效果时，部分电脑上搜索框的字边上有蓝橙彩边（#12）；“文件”里类型条收起时底栏会闪一下。
  **Fixes**: blue and orange fringes on text with transparency effects on some PCs (#12); the footer flickering as the kinds row closed.

## 升级提示 · Upgrading

内容搜索的大小上限默认值调小了：文本 16 MB、代码 2 MB、数据 4 MB、文档 100 MB（以前是 64、8、16、512），上限可以写小数。没改过的会换成新的默认值，自己改过的保持不变。超过上限的文件搜完会提示，点一下就能搜。

The default size limits of content search are smaller: text 16 MB, code 2 MB, data 4 MB, documents 100 MB (were 64, 8, 16, 512), and decimals are allowed. Limits you never changed take the new defaults; ones you set stay. Files over the limit are offered after a search, one click away.
