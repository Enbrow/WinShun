## 新功能 · What's new

- 🛠️ **Windows 10 LTSC 上能打开了**：0.7.x 在 Windows 10 2004 之前的版本（如 LTSC 2019）上一启动就报“无法定位程序输入点”，现在修好了（#15）。
  **Starts on Windows 10 LTSC**: 0.7.x failed at launch with “entry point not found” on Windows 10 before 2004 (such as LTSC 2019); fixed (#15).
- 📂 **对话框什么时候自动转，可以选**：设置里“自动转到”下面多了“什么时候转”：对话框一出现就转，或者先停在上次保存的位置，从文件管理器切回来时再转（#14）。第一次在对话框旁看到文件管理器的文件夹时，搜索框下面会问一次要不要自动转。
  **Choose when dialogs go there by themselves**: under auto-jump, “When” picks as the dialog opens, or only after you come back to it from the file manager, so it first opens where Windows left it (#14). The first time a dialog could go to your file manager's folder, a line under the search bar asks once.
- 🪶 **不用时更省内存**：Win顺 不在前台一分钟后，把用不着的内存交还给系统，任务管理器里从一两百 MB 降到十几 MB；再打开搜索框只慢几毫秒。
  **Less memory while unused**: a minute after WinShun leaves the foreground it hands back memory it isn't using, from 100–200 MB down to about 15 MB in Task Manager; the search window opens only a few milliseconds slower.
- 🔎 **任务栏搜索框拖动更稳**：拖到开始按钮右边时，图标实时让出位置，松手就落在那里，不再来回跳；设置里会说明框为什么没显示（任务栏在侧边、自动隐藏、读不到图标等）。
  **Steadier taskbar box dragging**: dragged next to Start, the icons make room as you go and the box stays where you let go, without jumping back and forth; Settings says why the box isn't shown (taskbar at the side, auto-hidden, icons not readable…).
- 📦 **升级时不再报文件被占用**：AI 客户端（Claude、Cursor、VS Code）开着 Win顺 的 MCP 时，安装程序会先关掉它再替换文件。
  **No more “file in use” on upgrade**: the installer closes WinShun's MCP relay that an AI client (Claude, Cursor, VS Code) keeps open before replacing files.
