## 修复 · Fixed

- ⌨️ **开始菜单里打字（#66）**：开着“在开始菜单里打字，也用 Win顺 搜索”时，按 Win 后马上打字，有时开始菜单还没关掉，或者刚关又跳回来，打的字就进了 Windows 自己的搜索。现在要等 Win顺 的搜索框真的在最前面才把字打进去，开始菜单又跳回来时再关它一次。字打得太快、紧贴着 Win 键按下时，第一个字仍可能被 Windows 先拿走。
  **Typing in the Start menu (#66)**: with "Typing in the Start menu searches with WinShun" on, typing right after Win sometimes went into Windows' own search, when the Start menu had not closed yet or came back right after. The words are now typed only once WinShun's search box is really in front, and a Start menu that comes back is closed once more. A first letter pressed almost together with the Win key can still be taken by Windows.
