## 修复 · Fixed

- 🔌 **开机自启关不掉（#67）**：用过“管理员直读”后，开机自启是以管理员身份设的；Win顺 以普通方式打开时，设置里的开关一点又弹回去，托盘菜单也没反应。现在关的时候会弹出 Windows 的确认框，点“是”就能关掉。另外，设置窗口开着时从托盘改了开机自启，窗口里也会马上跟着变。
  **Start with Windows would not turn off (#67)**: after using 管理员直读 (direct read as administrator), Start with Windows was set up as administrator, and with WinShun started normally the switch in the settings snapped back and the tray item did nothing. Turning it off now asks Windows once (choose Yes). The settings window also follows a change made from the tray menu while it is open.
- 📦 **安装卡在替换字体文件上（#68）**：WinShun.exe 设了“以管理员身份运行”时，安装程序关不掉正在运行的旧版，替换文件时报“拒绝访问”，装完启动又报“请求的操作需要提升”。现在安装时会去掉这个设置（Win顺 要以普通方式启动，需要管理员读盘时用“管理员直读”），还关不掉旧版就请你先从托盘退出，不会再装到一半。
  **Setup stuck replacing a font file (#68)**: with "Run this program as an administrator" set on WinShun.exe, Setup could not close the running copy, failed to replace its files ("Access is denied") and then could not start it ("The requested operation requires elevation"). Setup now removes that setting (WinShun starts with normal rights; use 管理员直读 for elevated reads) and, if the old copy still runs, asks you to exit it from the tray instead of failing half way.
- 🗂️ **右键菜单里点了没反应的“用 Win顺 搜索此处”**：删掉的旧副本（比如以前的便携版）留下的这一项，在设置里关掉时也会一起删掉。
  **A "Search here with WinShun" item that did nothing**: one left behind by a deleted copy (an old portable folder, say) is now removed too when you turn the item off.

## 第一次打开 · First launch

Windows 可能提示“Windows 已保护你的电脑”：点 **更多信息 → 仍要运行**。程序还没有代码签名证书。为所有用户安装时要管理员同意一次，用来装索引服务；之后就不再要了。“只为我安装”不需要管理员同意。

Windows may say “Windows protected your PC”: click **More info → Run anyway**. The app is not code-signed yet. Installing for all users asks an administrator once, for the index service; after that, never again. Installing for you only needs no administrator.
