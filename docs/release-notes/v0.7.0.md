## 下载 · Download

下载下面的 **WinShun-0.7.0-x64-setup.exe**，双击安装。已经装了旧版的，直接运行它就能升级，设置和索引都保留。需要 Windows 10 或 11（64 位）。

Download **WinShun-0.7.0-x64-setup.exe** below and run it. If an older version is installed, running it upgrades in place and keeps your settings and index. Requires Windows 10 or 11, 64-bit.

## 新功能 · What's new

- 🧩 **插件**：在搜索框里打关键字用插件，结果和文件、应用列在一起。随包带了小工具（计算器、单位换算、颜色、时间戳、UUID、Base64、哈希）、结束进程、浏览器书签、翻译等，在设置 → 插件 里一张卡片一个，开关、关键字、权限、它自己的设置都在卡片里。插件总是以你的普通权限运行，要起子进程、读剪贴板的会在打开前列出来。也可以自己写：一个 plugin.json 就能做打开网页、跳到文件夹这类命令，脚本用什么语言都行。
  **Plugins**: type a keyword in the search box to use a plugin; its results mix with files and apps. Bundled: tools (calculator, units, colours, timestamps, UUID, Base64, hashes), kill a process, browser bookmarks, translate and more, one card each in Settings → Plugins with its switch, keywords, permissions and settings. Plugins always run with your normal rights, and the ones that start programs or read the clipboard say so before you switch them on. Write your own: a plugin.json alone makes commands that open a page or jump to a folder, and scripts can be in any language.
- 🤖 **给 AI 助手用的搜索**：在设置 → AI 助手 里一键连接 Claude Desktop、Claude Code、Cursor、VS Code，AI 就能用 Win顺 找文件名（拼音也行）和文件内容。默认只读，只看得到你平时不提权时看得到的文件；打开文件、读剪贴板历史、用插件各有开关，可以列出不让 AI 看到的文件夹，每次调用都有记录。
  **Search for AI assistants**: Settings → AI assistants connects Claude Desktop, Claude Code, Cursor or VS Code in one click, and the AI can find files by name (pinyin too) and by content through WinShun. Read-only by default and limited to what you can see without admin rights; opening files, reading the clipboard history and using plugins each have a switch, folders can be kept from the AI, and every call is logged.
- 🗄️ **网络共享文件夹**：NAS 或别的电脑上的共享文件夹也建索引，和本机文件一起搜；服务器关着时，读过的照样搜得到。在设置 → 搜索范围 里添加、登录、看每个共享的状态。
  **Network shares**: shared folders on a NAS or another PC are indexed and searched with your own files, and what was read stays searchable while the server is off. Add them, sign in and see each one's state in Settings → Search scope.
- ⭐ **收藏夹**：常用的文件夹、文件、应用和 Windows 设置，没打字时排在最前；给它们起关键字一打就开，收藏的文件夹按 `Tab` 进去。从资源管理器拖进设置 → 收藏夹 就能添加，可以排序、改名、导入导出；对话框旁的搜索框也列出同样的收藏。
  **Favorites**: the folders, files, apps and Windows settings you use most come first before you type; give them keywords to open them, and `Tab` goes into a favorite folder. Drag them from File Explorer into Settings → Favorites, reorder, rename, import and export; the bar by Open and Save dialogs lists them too.
- 📋 **剪贴板能搜图片里的字**：复制的图片由 Windows 自带的文字识别读出里面的字（在本机，不联网），搜索时一起找，预览里列在图下面。点一条现在是在右边预览，再点一下收起；点这一行的粘贴按钮或双击才粘贴，`Enter` 照旧粘贴。光标在搜索框末尾时按 `→` 也能开关预览，预览开着关掉剪贴板，下次打开还开着；图片的缩略图也大了。剪贴板开在别的程序上时，AutoHotkey、PowerToys 改过的键照常起作用。右上角的图钉能把剪贴板钉在最上面，一条接一条地往表格、表单里填。
  **Clipboard**: the words in copied pictures are found by the search, read by Windows' own text recognition on your PC (nothing goes online) and listed under the picture in the preview. A click on an entry now shows it in the preview (click again to close); its paste button or a double click pastes, and `Enter` still does. `→` at the end of the search opens and closes the preview, which stays open next time if you left it so; pictures have larger thumbnails. Keys remapped with AutoHotkey or PowerToys work while the clipboard is open over another program. The pin at the top right keeps the clipboard on top, to fill in a table or form one entry after another.
- 🔎 **结果列表**：把文件和文件夹直接拖到聊天、邮件或资源管理器里；在终端里打开文件所在的文件夹；输入路径的一段（`tools/screenshots`）直接进去；搜的词出现在上级文件夹名里也算，并标出来；“最新在前 / 最早在前”在每个范围里都能用，滚到底接着加载更多；内容搜索的摘要把每个搜的词都显示出来。网页搜索内置了十个常用网站，各用自己的图标，可以导入导出、换成自己的图标。
  **Results**: drag files and folders straight into a chat, an email or File Explorer; open a file's folder in Terminal; type part of a path (`tools/screenshots`) to go there; words found in the folders above a file count and are highlighted there; newest or oldest first works in every scope and scrolling to the end loads more; content snippets show every word you searched. Web search has ten common sites built in with their own icons, import and export, and your own icons.
- 🛠️ **修复**：设置窗口开着时按 Win 键开始菜单不出来（#4）；文件内容搜索可以整个关掉（#5）；WPS 的“打开”“另存为”对话框（#6）；从资源管理器切回对话框又能自动转过去了（#7）；往设置窗口拖文件会让 Win顺 退出；彩色底上的字一律是白色，任何强调色都看得清。
  **Fixes**: the Start menu not opening with the settings window in front (#4); a switch to turn file content search off entirely (#5); WPS Open and Save dialogs (#6); jumping again after a visit to File Explorer (#7); dropping files on the settings window closed WinShun; words on coloured fills are white, readable with any accent colour.

## 升级提示 · Upgrading

升级后，剪贴板历史里以前存的图片会在后台读一遍里面的字，之后就能搜到。识别用的是 Windows 语言包里的“光学字符识别”，添加中文语言时一般会一起装上。

After upgrading, the pictures already in the clipboard history are read once in the background, then their words can be found. Recognition uses the optical character recognition of a Windows language, usually installed with the language.

浏览器书签和翻译插件需要装有 Python 3。

The bookmarks and translate plugins need Python 3.
