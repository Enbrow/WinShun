## 第一次用

1. 从 [Releases 页面](https://github.com/LingCore/WinShun/releases/latest) 下载安装程序，双击安装。Windows 提示“已保护你的电脑”时，点 **更多信息 → 仍要运行**。
2. 装好后，屏幕右下角的托盘里会出现 Win顺 的图标。索引几秒钟就建好。
3. **连按两下 Ctrl**，屏幕中间弹出搜索框，直接打字就行。再连按两下 Ctrl 或按 `Esc` 关闭。

> 双击 Ctrl 和别的软件冲突（比如 Listary、PowerToys 的“查找鼠标”）？在 **设置 › 打开 Win顺** 里可以只认左边或右边的 Ctrl，或者换成别的组合键，比如 `Alt+Space`。

右键托盘图标可以打开设置、重建索引、暂停记录剪贴板、退出。

## 搜文件

### 打字就出结果

- 打文件名的一部分就行，不用打全：打 `报告` 能找到“2024 年度报告.docx”。
- **拼音也行**：`ndbg`（首字母）、`niandubaogao`（全拼）都能找到“年度报告”，可以混着打。
- **打错同音字也能找到**：打成“年度报高”找不到时，Win顺 会自动按读音再找一遍。
- **多个词用空格隔开**，顺序不限：`报告 2024` 要求两个词都有，也可以有一个出现在所在文件夹的名字里。

### 选哪个结果

- `↑` `↓` 移动，`Enter` 打开。
- `Ctrl+Enter` 打开文件所在的文件夹，并选中这个文件。
- `Ctrl+Shift+Enter` 以管理员身份运行。
- **数字键直达**：每行图标上标着序号，按 `Ctrl+1`～`Ctrl+9` 直接打开第几行（设置里可以改成 `Alt`）。
- `Ctrl+C` 复制文件（可以粘贴到资源管理器、微信），`Ctrl+Shift+C` 复制路径。
- 结果可以直接**拖出去**：拖进微信、邮件、资源管理器都行。
- **右键**一行有更多操作：打开位置、复制路径、加入收藏、在终端中打开等。按住 `Shift` 右键，或者点菜单里的“更多选项”，出现的是 Windows 自己的右键菜单（和资源管理器里一样），选中几行也行；复制、剪切、删除之后搜索框不关。
- **多选**：`Shift+↓`、`Ctrl+单击`、`Shift+单击` 都能选多行，再一起复制或拖出去。
- **缩略图**：图片、视频、PDF 等显示缩略图，代替类型图标；“打开”“另存为”对话框旁的搜索框里也一样。不想要的话，在 **设置 › 结果列表** 里关掉“显示图片缩略图”。

### 名字太长

名字放不下时，在中间缩短，扩展名和结尾留着（“…第二版.xlsx”）。

- 鼠标在这一行上停一下，显示完整的名字、位置、大小、修改时间和创建时间。搜索面板的名称列、对话框旁的搜索框里也一样。
- 想一眼看全：拖动搜索框的左边或右边把它调宽，宽度会记住。双击边缘恢复默认，或者在 **设置 › 外观 › 搜索框宽度** 里点“恢复默认宽度”。

### 范围：全部 / 文件 / 内容

搜索框右上角有三个范围，按 `Tab` 往后切，`Shift+Tab` 往前切：

| 范围 | 搜什么 |
|---|---|
| **全部** | 文件、文件夹、应用、系统设置、网页、收藏，混在一起按匹配度排 |
| **文件** | 只要文件和文件夹 |
| **内容** | 搜文件里的文字，见[搜文件里的文字](#搜文件里的文字) |

在 **文件** 里，搜索框下面有一排类型：文件夹、文档、图片、视频、压缩包、程序……按 `Ctrl+Tab` 依次切换，或者直接点。点 `+` 可以加自己的类型，比如把 `xlsx`、`xls`、`csv` 叫做“表格”。

### 排序

按 `Ctrl+S`，或者点底栏左边的按钮，在三种排序之间切换：

- **最匹配**：名字最像的在前，你自己的文件排在系统目录、`node_modules` 前面。
- **最新**：最近修改的在前。
- **最早**：最早修改的在前。

**程序优先**：按最匹配排时，名字差不多的结果里，程序和脚本排在前面：搜 `curl`，`curl.exe` 排在文件夹 `curl` 和 `curl.h` 前面。优先哪些类型，在 **设置 › 结果列表 › 优先显示的文件类型** 里改（默认 exe、bat、cmd、ps1、msi，用分号或逗号隔开），留空就不优先。

修改时间比现在晚一天以上的文件（相机、别的电脑上时钟错了的），按时间排序时排在最后。

### 什么都不打的时候

搜索框是空的时候，列出你**最近打开**的或**最近修改**的文件，可以在底栏或设置里换，也可以设成什么都不显示（只留收藏）。

如果不想让别人看到你上次搜了什么，在设置里打开“每次打开时清空搜索”。

### 搜索语法

| 写法 | 意思 |
|---|---|
| `报告 2024` | 两个词都要有，顺序不限 |
| `ndbg`、`niandubaogao` | 拼音首字母、全拼，可以混用 |
| `"年度 报告"` | 引号里的当成一个整体 |
| `!草稿` | 排除名字里有“草稿”的 |
| `!node_modules\` | 排除这个文件夹里的 |
| `*.pdf`、`报告?.docx` | 通配符：`*` 任意多个字，`?` 一个字 |
| `ext:pdf,docx` | 只要这些扩展名 |
| `项目\readme` | 在名字里有“项目”的文件夹下面找 readme |
| `D:\My Files\`、`tools/out/` | 路径直达：按回车进去，列出里面的东西，接着打字在里面找 |
| `size:>10mb`、`size:1mb..5mb` | 按大小（见[搜索面板](#搜索面板筛选和排序)） |
| `dm:7d`、`dm:today`、`dm:2026-01` | 按修改时间 |

### 搜得到哪里

- 所有本地磁盘。U 盘、移动硬盘在设置里可以选择收录；没收录的 U 盘插着时，列表末尾会提示你顺手搜一下它。
- **NAS 和局域网共享文件夹**：在设置里加进来，就和本地文件一起搜；服务器关机时，收录过的文件照样搜得到。
- 新建、改名、删除的文件马上就能搜到，不用等。

## 搜索面板：筛选和排序

结果太多、想慢慢挑的时候，用搜索面板。

- **打开**：按 `Ctrl+E`，或者点搜索框右上角的展开按钮（两个斜箭头）。同一个窗口会展开成大面板，已经打的字、选的范围都还在。
- **收回**：再按 `Ctrl+E`，或者点面板右上角的按钮。

### 左边：筛选

| 筛选 | 选项 |
|---|---|
| 范围 | 全部、文件、文件夹、内容 |
| 类型 | 文档、图片、视频、音频、压缩包、程序、电子书、代码，还有你自己加的类型 |
| 修改时间 | 今天、最近 7 天、最近 30 天、今年，或者自定义起止日期 |
| 大小 | 小于 1 MB、1～100 MB、100 MB～1 GB、大于 1 GB，或者自定义范围 |
| 位置 | 收藏的文件夹，或者点“选择文件夹…”挑一个 |

几个筛选可以叠在一起用。点“清除全部”一次全取消。

**不打字也能用**：只选筛选条件，就会列出整台电脑上符合条件的文件。比如只选“大于 1 GB”，就能看到硬盘上所有的大文件；再点“大小”列头排一下，最大的在最前。

### 右边：按列排序

结果分成 **名称 / 路径 / 大小 / 修改时间** 四列，点列头按这一列排序，再点一次倒过来。

### 直接在搜索框里写条件

不想点筛选的话，也可以把条件直接写在搜索框里，普通搜索框和面板里都能用：

| 写法 | 意思 |
|---|---|
| `size:>100mb` | 大于 100 MB |
| `size:1mb..5mb` | 1 MB 到 5 MB 之间 |
| `size:large` | 用 Everything 的叫法表示大小档 |
| `dm:today` | 今天修改的 |
| `dm:7d` | 最近 7 天修改的 |
| `dm:2026-01` | 2026 年 1 月修改的 |
| `报告 size:>1mb dm:30d` | 名字有“报告”、大于 1 MB、最近 30 天改过的 |

面板的大小和位置会被记住。下次双击 Ctrl 打开的还是普通搜索框，需要时再按 `Ctrl+E` 展开。

## 钉住和移动搜索框

平时搜索框像菜单一样：点了别处、打开了文件，它就自己收起来。想一边看一边搜的时候，可以把它**钉住**：

- 按 `Ctrl+T`，或者点搜索框右上角的图钉。钉住后图钉变成实心的，底栏会提示。
- 钉住后，点别的窗口、打开文件，搜索框都留着，并且一直在最上层。
- 按 `Esc` 照样关闭；下次打开还是钉住的。再按 `Ctrl+T` 取消。重新启动 Win顺 后恢复成不钉住。
- 钉住时搜索框在别的窗口后面，双击 Ctrl 会把它拿到前面来，位置不变。

**移动窗口**：按住搜索框左边的放大镜拖动，就能把窗口挪到别处。**单击**放大镜打开设置。

## 预览文件

在结果上按 `Alt+P`（或者右键选“预览”），不用打开就能看一眼文件，搜索框也不会关。

- **能预览的**：图片；文本和代码（自动识别 UTF-8、GBK）；Word、Excel、PowerPoint、PDF（用和资源管理器预览窗格同样的预览程序，所以要装了对应的软件）；文件夹显示里面有几个文件夹、几个文件。别的文件显示大图标和类型、大小、时间。
- **换一个文件**：按 `↑` `↓` 换一行，预览跟着换。鼠标指着哪一行，就预览哪一行。
- **关闭预览**：再按 `Alt+P`，或者按 `Esc`。再按一次 `Esc` 才关搜索框。
- **QuickLook、Seer 用户**：如果后台开着 QuickLook 或 Seer，Win顺 会交给它们来预览。不想这样的话，在设置的“预览文件（Alt+P）”里改成“内置”。
- 从网上下载的文件，和资源管理器一样，为了安全只显示文件信息，不调用预览程序。

## 搜文件里的文字

想不起文件名、只记得里面写了什么时，用 **内容** 范围（按 `Tab` 切过去）。

- **能搜的文件**：
  - 纯文本：txt、md、log、csv、json、各种代码；
  - 文档：Word、Excel、PowerPoint、PDF、WPS。
- **结果**：显示命中的那一行。文档会告诉你在第几页、第几张幻灯片、哪个表的第几行。
- **怎么搜**：可以写多个词，用引号找整个短语，结果按相关度排。
- **只在某个文件夹里搜**：在词后面写文件夹名和斜杠。
  - `年度报告 财务/`：只在叫“财务”的文件夹里找；
  - `工作/财务/`：只要“工作”下面的那个“财务”；
  - 同名的文件夹有好几个时，搜索框下面会列出来，按 `Ctrl+Tab` 挑一个；
  - 也可以点下面的收藏文件夹，或者在结果的文件夹上右键“在此文件夹中搜内容”。
- **没搜到的文件**：太大的、系统目录里的、类型没列进来的，默认不搜；搜完会告诉你各有几个，点一下就临时把它们也搜了。要搜哪些类型、大小上限是多少，在设置里改；大小上限可以小到 KB，直接打 `50k`、`1.5m`、`2g` 也行。

第一次建内容索引要把文件读一遍。安装版由索引服务直接从磁盘读文本文件，杀毒软件不用一个个检查，很快就好；Word、PDF 这些文档，和便携版没装索引服务时，还是一个个打开，开着杀毒软件会慢一些。之后只读改过的文件，就很快了。

## 打开应用和系统设置

- **应用**：开始菜单里的所有应用都能搜，包括 Microsoft Store 应用。名字、拼音、首字母（`vsc` 找到 VS Code）、程序名（`winword`）都行。
- **系统设置**：打“网卡”、`shipeiqi`（适配器）或 `ncpa.cpl` 都能直接打开网络连接，打“卸载”出应用列表。大约 1200 个 Windows 设置页和控制面板项，还补了组策略、磁盘管理、hosts、AppData 这些开始菜单里找不到的。

## 网页搜索

在关键词后面加个空格，就在那个网站上搜：

- `baidu 天气`、`zhihu 显卡`、`jingdong 键盘`、`bilibili 教程`
- 先打关键词，结果第一行是那个网站，按空格、`Enter` 或 `Tab` 进去，再打要搜的词。

自带百度、必应、B 站、知乎、微博、抖音、小红书、淘宝、京东、翻译。

### 搜索建议

打了网站关键词再打字，下面会列出那个网站的联想词：

- `Enter`：直接搜这一条；
- `Tab`：把它填进搜索框，接着改。

百度、必应、B 站、淘宝自带建议。只有你打了网站关键词，Win顺 才会把你打的字发给**那一个**网站取建议；平时搜文件一个字也不发。不想要的话，在设置的网页搜索里关掉“网页搜索建议”。

### 添加自己的网站

在设置的网页搜索里点“添加”：

- **网址**：把搜索结果页的网址里搜索词换成 `%s`，比如 `https://www.so.com/s?q=%s`；
- **关键词**：比如 `so`；
- **建议接口**（可选）：同样用 `%s`，填好就有搜索建议，改了马上生效，不用重启；
- **图标**：可以选图片或 SVG 文件，也可以点“粘贴 SVG”，直接贴 iconfont 上“复制 SVG 代码”复制来的内容。

网站列表和图标都可以导入、导出。

## 收藏夹

- 在结果上右键“加入收藏夹”。不打字时，收藏的排在最前。
- 给收藏起个**关键词**，以后一打关键词就能打开。
- 收藏的文件夹选中后按 `Tab`，就进到里面接着搜。

## 插件

随 Win顺 一起装好的小工具：

| 打什么 | 做什么 |
|---|---|
| `= 1+2*3` | 计算器 |
| `12 inch to cm` | 单位换算 |
| `#ff8800` | 颜色值换算 |
| 时间戳、UUID、Base64、哈希 | 常用的转换 |
| `kill 进程名` | 结束进程 |
| `bm 关键词` | 搜浏览器书签 |
| `tr 文字` | 翻译 |

“按意思找”可以用本机的 Ollama、LM Studio（什么都不上传），也可以填硅基流动、百炼、OpenAI 等的密钥。用云服务时，第一次计算前会告诉你要发出去多少字，按回车才开始。

想自己写插件，见 [docs/plugins.md](plugins.md)。

## “打开”“另存为”对话框

在别的软件里点“打开”“另存为”，或者在网页上传文件时：

- **对话框旁边的搜索框**：打文件夹或文件名（拼音也行），回车，对话框直接转过去，不用一层层点。WPS 的对话框也认。
- **`Ctrl+G`**：转到资源管理器（或 Total Commander、Directory Opus、XYplorer）正在显示的那个文件夹。
- **不打字时**：列出开着的文件夹、刚复制的路径、收藏和最近用过的文件夹。
- **自动转过去**：可以设成对话框一出现就转到资源管理器的文件夹；或者先停在上次的位置，等你从资源管理器切回来时再转。
- 拖动对话框或调整它的大小时，旁边的搜索框先藏起来，松手后出现在新的位置。

## 在资源管理器里

### 双击空白处

在资源管理器或桌面的**空白处双击**，弹出一个文件夹菜单：收藏的、最近的、别的窗口里开着的文件夹。选一个，当前窗口就转过去（在桌面上会开新窗口）。菜单里还能在当前文件夹里搜、把它加进收藏。

- 方向键、回车、`Esc`、首字母都能用；点别处或再双击就关。
- **Directory Opus 里也能双击**：在 **设置 › 打开 Win顺 › 对话框** 里打开“在 Directory Opus 的空白处双击”，Win顺 替你在 Opus 的设置里加好命令（Opus 会重启一下）；关掉或卸载时换回原来的。
- 双击被别的软件占了，或者想在 Total Commander、XYplorer 里用？在设置里给文件夹菜单设一个快捷键（“用快捷键弹出文件夹菜单”），在任何窗口里按一下就弹出，再按一次关闭。

### 右键“用 Win顺 搜索此处”

在文件夹、文件夹的空白处、磁盘上右键，选“用 Win顺 搜索此处”，搜索框带着这个文件夹打开，接着打字就只在里面找。Windows 11 上在“显示更多选项”里。设置里可以关掉。

### 直接打字搜索

在资源管理器的文件列表里**随便打字**，Win顺 就弹出来，带着你打的字，只搜这个窗口所在的文件夹（和 Listary 一样）。

- 中文输入法照样能用，拼音会在 Win顺 的搜索框里继续组字。
- 按 `Esc` 回到资源管理器。
- 改名、地址栏、资源管理器自己的搜索框里打字不会触发；按着 `Ctrl`、`Alt`、`Win` 时也不会。
- **默认关**：它代替了资源管理器自己的“按首字母跳到文件”。在 **设置 › 打开 Win顺** 里打开“在资源管理器里直接打字搜索”。

## 剪贴板历史

复制过的文字、图片、文件都记下来，随时找回来再贴。

- **打开**：在设置里打开“用 Win+V 打开，代替 Windows 自带的剪贴板”后按 `Win+V`；不想换掉 Win+V 的话，也可以自己设一个快捷键，比如 `Win+Alt+V`。它开在输入光标旁边，不抢焦点。
- **粘贴**：双击或 `Enter` 粘贴；`Shift+Enter` 粘贴为纯文本；`Alt+1`～`Alt+9` 直接粘贴第几条。
  - 想像 Windows 自带的剪贴板那样**点一下就粘贴**（比如用手机远程操作电脑时），在 **设置 › 剪贴板** 打开“单击粘贴”。打开后，鼠标移到一条上出现的按钮从“粘贴”变成“预览”；按住 Ctrl 或 Shift 点击仍是多选。
- **搜索**：打字就能搜，拼音也行；`@wx` 只看从微信里复制的。**图片里的字也能搜**（在本机识别，不联网）。
- **预览**：`Alt+P` 看全文、大图，颜色值显示 HEX / RGB / HSL。觉得图片缩略图太小，在 **设置 › 剪贴板** 打开“大图片缩略图”，不打开预览也看得清。
- **拖出图片**：按住一张图片拖到文件夹里，就存成 PNG 文件。
- **整理**：
  - 固定常用的，可以让固定的排在最前；顺序可以拖动，或者用 `Ctrl+↑` `Ctrl+↓` 调整；
  - 分组；
  - 多选后按选的顺序一起粘贴；
  - 钉住剪贴板窗口，一条接一条地往表格里填。
- **隐私**：密码管理器复制的密码不记录；历史只存在本机。托盘菜单里可以暂停记录。

## 任务栏搜索框

在设置里打开后，Win顺 在 Windows 11 的任务栏上放一个自己的搜索框（Windows 10 是一个按钮），点它，结果从任务栏上方滑出来。

- **样式**：和 Windows 搜索一样三选一：搜索框、图标和标签、仅图标（像任务栏上的一个按钮）。在 **设置 › 打开 Win顺 › 任务栏** 的“搜索框样式”里选。
- Windows 11 原生任务栏上，可以打开“放在开始按钮右边”，和 TranslucentTB 一起用也行。空间不足时搜索框会先缩短，再变成标签或图标。
- 便携版或开发版提示需要定位组件时，点“准备定位组件”，在 Windows 管理员提示中选“是”；完成后自动重试，Win顺 本身仍用原来的权限运行。
- StartAllBack / ExplorerPatcher 启用经典任务栏时，目前搜索框放在应用图标两侧；“放在开始按钮右边”只支持 Windows 11 原生任务栏。
- 搜索框可以单独使用，也可以与 Windows 搜索并存；是否隐藏 Windows 搜索、接管 `Win+S` 或开始菜单打字，都按需选择。
- 按住搜索框可以拖到任务栏上别的位置。

## 给 AI 助手用（MCP）

Win顺 可以当作 MCP 服务器，让 AI 助手（Claude Desktop、Claude Code、Cursor、VS Code 等）用它搜文件名、文件内容和最近修改的文件。

- 在设置里一键连接这些客户端。
- 默认只读，只看得到 AI 客户端本来就有权限看的文件。
- 可以设置不让 AI 看到的文件夹；每次调用都有记录。

## 外观、设置和备份

- **外观**：浅色、深色跟随系统。**界面大小**有紧凑、标准、宽松三档。托盘和任务栏的图标可以换成单色。
- **找设置**：设置窗口里按 `Ctrl+F` 搜索，`kjj` 就能找到“快捷键”。改了立即生效。
- **文件管理器**：打开文件夹、打开所在位置时用哪个，在 **设置 › 打开 Win顺 › 对话框** 里选：资源管理器、Total Commander、Directory Opus、XYplorer（装了的才列出），或者选“其他（自定义）”，填别的文件管理器打开文件夹和显示文件的命令（`{path}` 会换成路径）。用自定义的文件管理器时，`Ctrl+G` 和对话框的建议只认上面四个。
- **索引位置**：设置 › 高级 › 索引位置，可以把索引挪到其他硬盘。
- **备份**：设置 › 高级里选一个文件夹（放在网盘的同步文件夹里就等于云备份）。设置、收藏、对话框的固定项、自己加的网页图标和插件会自动备份，保留最近 10 份，随时恢复。
- **更新**：有新版本时托盘会提醒。Win顺 不会自己下载、替换程序文件，升级时运行新的安装程序，设置和索引都保留。

## 常见问题

**双击 Ctrl 没反应？**
看托盘里有没有 Win顺 的图标。Listary、PowerToys 的“查找鼠标”默认也用双击 Ctrl，关掉其中一边，或者在 Win顺 里只认左 Ctrl、右 Ctrl，或换成组合键。全屏玩游戏、鼠标被隐藏时，Win顺 默认不响应双击 Ctrl。

**刚装好，搜不到刚建的文件？**
新建、改名的文件马上就能搜到。如果一直搜不到，右键托盘图标选“重建索引”。

**内容搜索第一次很慢、磁盘一直在忙？**
第一次建内容索引要把文件读一遍。安装版由索引服务直接从磁盘读文本文件，杀毒软件不用逐个检查，一般很快就好。便携版没装索引服务时一个个打开文件，杀毒软件（特别是 Windows Defender）会逐个检查，所以会慢一些、磁盘忙一阵；可以在 **设置 › 搜索范围 › 磁盘 › 索引方式** 里装上索引服务。建好之后只读改过的文件，就不忙了。

索引很慢或其他功能出问题时，到 **设置 › 高级 › 诊断日志** 点 **导出诊断日志**。程序会打开诊断文件夹，把其中的 `WinShun-diagnostics.zip` 发给开发者即可；设置里搜索“诊断”也能找到。安装版的目录是 `%LOCALAPPDATA%\WinShun\diagnostics`，便携版在程序旁的 `data\diagnostics`；用了自定义配置目录时跟随那个目录。

诊断包包含版本、系统和权限、磁盘类型、索引进度与耗时、直读及回退情况、慢读取和运行错误；不包含设置文件、剪贴板、搜索历史、AI/插件对话或文档正文。运行错误可能带文件路径。诊断记录每份最多 1 MB、最多保留 3 份；7 天未更新的诊断文件在启动、写入或导出时自动清理。导出包固定为同一文件名，每次覆盖上一份，不会不断积累。程序和索引服务原有的错误日志各保留当前与上一份，诊断导出对每份最多读取最近 1 MB。

**往管理员身份运行的程序里粘贴不进去？**
Windows 不让普通权限的程序往管理员程序里打字。这时 Win顺 会把内容复制好，提示你按 `Ctrl+V`。

**占多少内存？**
每 100 万个文件约 30 MB，用着的时候一般 120～140 MB；一分钟不用后，任务管理器里降到十几 MB。

**会上传数据吗？**
不会上传你的文件和索引。只在这些时候联网：检查新版本（可以关）；第一次显示某个网站时取它的图标；打了网站关键词后取搜索建议；你自己打开“按意思找”并选了云服务时。

更多问题欢迎到 [Issues](https://github.com/LingCore/WinShun/issues) 或 [LINUX DO 的帖子](https://linux.do/t/topic/2996093) 里提。
